# Public adoption evidence

This ledger indexes independently checkable use of Flight Recorder in public
open-source repositories. External records—not this page—are the authority.

## Current verified state

No qualifying external adoption is recorded yet.

Flight Recorder's own workflows, TechBantu-controlled repositories, forks,
templates, demo-only repositories, unmerged pull requests, short-lived
installations, reciprocal contribution arrangements, paid installations, and
automated activity are excluded.

## Inclusion rule

An adoption entry must link all of the following:

1. an outside-owned, non-fork public repository;
2. a maintainer-merged default-branch workflow that pins Flight Recorder to a
   full commit SHA;
3. a meaningful existing check wrapped by the Action;
4. a successful public workflow run;
5. a later successful run or upgrade showing continued use; and
6. the first and most recent independently observed dates.

A security-conscious project may use the Action without appearing here. No
telemetry, phone-home event, or private usage claim will be used to infer
adoption.
